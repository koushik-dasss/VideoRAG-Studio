# VideoRAG-Studio

VideoRAG-Studio is an AI-powered platform that aims to transform videos into a searchable knowledge base.

The goal of this project is to allow users to:

- Upload videos
- Generate transcripts automatically
- Create AI-generated chapters
- Search video content semantically
- Ask questions about videos
- Navigate directly to relevant timestamps

## Planned Tech Stack

### Frontend
- React
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### AI Services
- OpenAI Whisper / Gemini
- Embedding Models
- Vector Search
