# 🔍 Troubleshooting Guide

Common issues, root causes, and recommended fixes for VideoRAG Studio.

---

## 1. Redis Connection Refused (`ECONNREFUSED 127.0.0.1:6379`)

### Symptom
Backend outputs error: `Redis connection to 127.0.0.1:6379 failed - connect ECONNREFUSED`.

### Solution
Ensure the Redis Docker container is running on port `6379`:
```bash
docker ps
# If stopped, start it:
docker start redis-server
# If not created:
docker run -d --name redis-server -p 6379:6379 redis:7-alpine
```

---

## 2. MongoDB Atlas Connection Timeout (`MongoServerSelectionError`)

### Symptom
Backend fails to connect to MongoDB Atlas with `Could not connect to any servers in your MongoDB Atlas cluster`.

### Solution
1. Verify `MONGODB_URI` string in `.env`.
2. Ensure your local machine's public IP address is whitelisted in **MongoDB Atlas -> Network Access -> IP Access List**.
3. For local development, whitelist `0.0.0.0/0` under Network Access.

---

## 3. Gemini API 429 Quota Exceeded

### Symptom
Log output: `Provider gemini rate limit exceeded` or `429 You exceeded your current quota`.

### Solution
1. Obtain a fresh API key from [Google AI Studio](https://aistudio.google.com/).
2. Update `GEMINI_API_KEY` in root `.env`.
3. Restart the backend process (`npm --prefix apps/backend run dev`).

---

## 4. Ollama Embedding Provider Error (`nomic-embed-text`)

### Symptom
Log output: `Ollama Verification Failed: model 'nomic-embed-text' not found` or `connect ECONNREFUSED 127.0.0.1:11434`.

### Solution
1. Ensure Ollama service is running locally (`ollama serve`).
2. Pull the required embedding model:
   ```bash
   ollama pull nomic-embed-text
   ```
3. Test embedding response:
   ```bash
   curl http://localhost:11434/api/embeddings -d "{\"model\":\"nomic-embed-text\",\"prompt\":\"test\"}"
   ```

---

## 5. Express API Unresponsive During Video Processing

### Symptom
Dashboard or API calls hang while a video is being transcribed.

### Solution
Ensure `videoProcessor.ts` passes `speechFactory` to `SpeechRecognitionService` instead of forcing a main-thread provider override. This offloads ONNX computation to a dedicated `worker_threads` thread (`transcriptionThread.ts`), leaving the main HTTP loop free.

---

## 6. Vector Search Returns Zero Results

### Symptom
Natural language queries in `/search` return empty arrays even though videos are processed.

### Solution
1. Verify the Atlas Vector Search Index `vector_index` is created on the `chunks` collection.
2. Confirm the index JSON definition specifies `path: "embedding"`, `numDimensions: 768`, and `similarity: "cosine"`.
3. Confirm that chunk embeddings were generated by checking document count in `chunks` collection.
